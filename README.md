DeepSeek KaTeX 渲染器的Windows版本

在 App 内打开 chat.deepseek.com，并自动注入 KaTeX 渲染脚本，让对话中的 LaTeX 公式和 CSS 代码块正确渲染。

## 功能
- 渲染行内公式 `$..$`、`\(..\)` 与块级公式 `$$..$$`、`\[..\]`、`\begin{..}\end{..}`
- 渲染 ```math / ```latex / ```tex 代码块
- 自动应用回复中的 CSS 代码块
- 登录状态保持，支持网页内文件上传，返回键走网页历史
- 公式内中文使用 Noto Sans CJK SC 回退字体

## 安装
1. 下载下方的 `app-debug.apk`
2. 传到手机后点开安装，按提示允许"未知来源"
3. 打开 App，登录 DeepSeek 账号即可使用

## 说明
- 最低支持 Android 7.0（API 24）
- 此为 debug 签名版本，仅供个人使用
- 渲染脚本与 Windows 版完全一致
